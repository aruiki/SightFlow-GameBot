# ノード一覧

> このファイルは `python -m sightflow nodes-doc > docs/nodes.md` で自動生成しています。
> 手で編集せず、`sightflow/graph.py` のノード定義を変えてから作り直してください。

線（データ）の種類: **リスト** / **物体** / **数** / **はい/いいえ** / **なんでも**。
入力が未接続のときは、同じ名前の設定値（あれば）か、既定値（操作ノードの「実行」は常に はい）が使われます。

## 見る

### 物体  `objects`

検出されたラベルの物体をすべて出力（近い順）

- 出力: リスト（リスト）、数（数）、ある（はい/いいえ）
- 設定「ラベル」

### 自分  `me`

基準になる自分の位置（設定の『自分のラベル』）

- 出力: 自分（物体）、見つかった（はい/いいえ）

### 動き  `motion`

自分の実際の移動速度と、壁などに引っかかっているか

- 出力: 速度（数）、引っかかり秒（数）、引っかかり（はい/いいえ）
- 設定「引っかかり判定(秒)」、既定 `0.4`

### 時間  `clock`

開始からの経過秒数

- 出力: 秒（数）

## 選ぶ

### いちばん近い  `nearest`

リストから自分にいちばん近い物体

- 入力: リスト（リスト）
- 出力: 物体（物体）、見つかった（はい/いいえ）

### いちばん遠い  `farthest`

リストから自分にいちばん遠い物体

- 入力: リスト（リスト）
- 出力: 物体（物体）、見つかった（はい/いいえ）

### 範囲内  `within`

自分から半径以内の物体だけ残す

- 入力: リスト（リスト）、半径（数）
- 出力: リスト（リスト）、数（数）
- 設定「半径(px)」、既定 `250`

### IDで探す  `by_id`

追跡IDが一致する物体（同じ敵を追い続ける）

- 入力: リスト（リスト）、ID（数）
- 出力: 物体（物体）、見つかった（はい/いいえ）

### ロックオン  `lock_on`

一度選んだ物体を追跡IDで追い続ける。見失ったら一番近いものに乗り換え

- 入力: リスト（リスト）
- 出力: 物体（物体）、見つかった（はい/いいえ）、切り替えた（はい/いいえ）
- 設定「見失い猶予(秒)」、既定 `0.5`

### 値を取り出す  `field`

物体の距離・座標・ID などを数値で取り出す

- 入力: 物体（物体）
- 出力: 値（数）
- 設定「項目」（distance / x / y / w / h / id / score / angle / exists）、既定 `distance`

## 判断

### 比べる  `compare`

a と b を比べて true / false

- 入力: a（数）、b（数）
- 出力: 結果（はい/いいえ）
- 設定「比較」（< / <= / > / >= / == / !=）、既定 `<`
- 設定「b」、既定 `200`

### かつ  `and`

両方 true なら true

- 入力: a（はい/いいえ）、b（はい/いいえ）
- 出力: 結果（はい/いいえ）

### または  `or`

どちらか true なら true

- 入力: a（はい/いいえ）、b（はい/いいえ）
- 出力: 結果（はい/いいえ）

### ではない  `not`

true と false を反転

- 入力: 入力（はい/いいえ）
- 出力: 結果（はい/いいえ）

### 数  `number`

決まった数値

- 出力: 値（数）
- 設定「値」、既定 `100`

### 計算  `math`

a と b を計算

- 入力: a（数）、b（数）
- 出力: 値（数）
- 設定「演算」（+ / - / × / ÷）、既定 `+`
- 設定「b」、既定 `1`

### 間隔をあける  `cooldown`

true が続いても、指定秒ごとに1回だけ true を出す

- 入力: 入力（はい/いいえ）
- 出力: 出力（はい/いいえ）
- 設定「間隔(秒)」、既定 `0.5`

### しばらく続ける  `hold_true`

一度 true になったら指定秒 true を保つ

- 入力: 入力（はい/いいえ）
- 出力: 出力（はい/いいえ）
- 設定「保つ秒数」、既定 `0.6`

## 操作

### 近づく  `move_toward`

対象に向かって移動（同時に複数あれば優先度が高いもの）

- 入力: 実行（はい/いいえ）、対象（物体）
- 設定「優先度」、既定 `1`

### 離れる  `move_away`

対象から離れるように移動

- 入力: 実行（はい/いいえ）、対象（物体）
- 設定「優先度」、既定 `2`

### 方向に移動  `move_dir`

決まった方向へ移動（上=0,-1 / 右=1,0）

- 入力: 実行（はい/いいえ）
- 設定「x」、既定 `0`
- 設定「y」、既定 `-1`
- 設定「優先度」、既定 `0`

### 横によける  `dodge`

引っかかった時用: 直前の移動方向の真横へ動く

- 入力: 実行（はい/いいえ）
- 設定「優先度」、既定 `9`

### 狙って撃つ  `aim`

攻撃ボタンから対象の方向へドラッグ（タッチ操作の照準）

- 入力: 実行（はい/いいえ）、対象（物体）
- 設定「ボタンx(0-1)」、既定 `0.88`
- 設定「ボタンy(0-1)」、既定 `0.78`
- 設定「ドラッグ長」、既定 `120`
- 設定「間隔(秒)」、既定 `0.4`

### クリック  `click`

対象の位置をクリック

- 入力: 実行（はい/いいえ）、対象（物体）
- 設定「間隔(秒)」、既定 `0.3`

### ここをクリック  `click_at`

画面上の決まった位置をクリック（ボタンなど）

- 入力: 実行（はい/いいえ）
- 設定「x(0-1)」、既定 `0.5`
- 設定「y(0-1)」、既定 `0.5`
- 設定「間隔(秒)」、既定 `1.0`

### キーを押す  `key`

キーを1回押す

- 入力: 実行（はい/いいえ）
- 設定「キー」、既定 `space`
- 設定「間隔(秒)」、既定 `0.5`
